HTML

What is HTML?

HTML stands for Hypertext Markup Language. It is the standard language used to crete Web pages. It tells the browser how to dislpay the web page.

Example HTML code

Code Explained:

  • <html>: root element of the HTML page. It requires a closing tag </html>.
  • <title>: tells the browser to display the content on the web page card. It requires a closing tag </title>.
  • <h1>: h1 defines a large heading in HTML. Closing tag is </h1>.
  • <h2>: h2 is a smaller heading tag. Heading tags go from h1 to h6, decresing in size.
  • <p>: Paragraph tag is used to define a paragraph. It's closing tag is </p>.
  • <img>: img tag is used to insert images in the web page. It is a self closing tag.
  • HTML also has lists. There are two types of lists in HTML:
    • Unordered list:
      • Apple
      • Orange
    • Ordered List:
      1. One
      2. Two

Table defining tags in HTML
